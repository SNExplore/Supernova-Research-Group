# Supernova Polarization Group

清华大学超新星偏振团队官方网站。

网站内容包括：

- 团队研究方向
- 杨轶（Yi Yang）、文旭东（Xudong Wen）及团队成员介绍
- 独立的亮点工作展示页面
- 超新星偏振相关的近期与代表性论文
- ArXiv 天体物理最新论文入口
- 团队联系方式

## 网站地址

<https://snexplore.github.io/Supernova-Research-Group/>

## 内容维护

- 首页内容：`index.html`
- 亮点工作：`highlights.html`
- 成员页面：`people/`
- 样式：`css/team.css`
- 交互：`js/team.js`
- 图片：`images/`

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。首次发布前，需要在仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**。

网站主视觉为项目原创生成图像；杨轶头像来自清华大学物理系官方个人页面。
