# Supernova Polarization Group

清华大学超新星偏振团队官方网站。

网站内容包括：

- 团队研究方向
- 杨轶（Yi Yang）与文旭东（Xudong Wen）的成员介绍
- 超新星偏振相关的近期与代表性论文
- 团队联系方式

## 网站地址

<https://snexplore.github.io/Supernova-Research-Group/>

## 内容维护

- 首页内容：`index.html`
- 成员页面：`people/`
- 样式：`css/team.css`
- 交互：`js/team.js`
- 图片：`images/`

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。首次发布前，需要在仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**。

网站中的仙后座 A 图像来自 NASA / ESA / CSA / STScI。
